# v0.21.0 macOS 수동 테스트 가이드

> 버그 수정 + 2차 반복 분석 결과 검증용 수동 테스트 문서
> 대상: `v0.21` (v0.20 이후 커밋 미배포분 포함)
> 작성일: 2026-08-06

## 0. 테스트 전 준비

```bash
./build_and_run.sh debug macos   # 있으면
swift build                      # 없으면 이걸로
swift run                        # 실행
```

- 실행 후 메뉴바 우측에 ▲▼ 속도 아이콘이 나타난다.
- 첫 실행이라면 온보딩 창이 떠야 한다 (v0.21 신규 수정).

## 1. 온보딩 / 권한

| # | 방법 | 기대 반응 |
|---|------|-----------|
| T-01 | 첫 실행 (또는 `defaults delete com.tetherlens.TetherLens hasShownOnboarding` 후 재실행) | 온보딩 창(앱 아이콘 + 위치/알림 권한 설명 + 시작 버튼)이 표시된다. 이전(v0.20)에는 절대 표시되지 않던 버그 |
| T-02 | 온보딩 "시작" 클릭 | 창이 닫히고 **위치 권한 프롬프트**가 이 시점에 뜬다 (런치 직후가 아니라). 권한 승인 시 DebugPanel에 "권한 승인됨" 로그 |
| T-03 | 온보딩 표시 중 창 닫기(빨간 버튼) | 권한 요청 없이 창만 닫힘. 재실행 시 온보딩 다시 표시 (완료 안 됐으므로) |
