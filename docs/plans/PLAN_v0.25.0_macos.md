# PLAN_v0.25.0_macos — 통계 전면 개편 (대시보드 인사이트 + 이동 이력 + 기간 리포트)

> 작성: 2026-08-06 (macOS)
> 기준 커밋: 9fb2459 (v0.24.0 완료)

## 1. 개요

현재 통계 화면(UsageReportView 5탭)은 "데이터 나열"에 그쳐 사용자가 직접 해석해야 한다.
벤치마킹(DataGuard/DataUsage/Data Usage Monitor 등)으로 "상황이 보이는 대시보드 + 이동 이력 + 기간 리포트"로 재구성한다.

## 2. 확정 범위 (사용자 선택 반영)

| 항목 | 결정 |
|------|------|
| 위치 정밀도 | **표현만 개선** — GPS/IP 출처·도시 수준 명시 (데이터 수집 변경 없음, GPS 3km 유지) |
| 이동 경로 | **타임라인 목록 + 지도 포커스** (폴리라인 제외) |
| 리포트 | **화면 표시만** (저장/공유 제외, 클립보드 복사 정도) |
| 리포트 주기 | **사용자 지정 기간만** (일/주/월/180/365, 자동 예약 없음) |

## 3. 구현 단계 (T-번호)

- **T-112** 리포트 대시보드 인사이트 카드 — 총/일평균/한도%/예상 소진일, 전기간 비교(▲▼), 최다 사용일·최다 핫스팟·상위 앱 요약
- **T-113** 그래프 고도화 — 기간 단위 세분화(day=시간대, week=요일, month=일, long=월) + 할당량 임계선(RuleMark) + 업+다운 누적 라인
- **T-114** 지도 핀 클러스터 + 위치 라벨 — 동일 좌표 반복 세션을 숫자 배지 클러스터로, GPS/IP 출처 배지
- **T-115** 이동 이력 타임라인 + 지도 포커스 — 세션 위치/IP 변경을 시간순 목록, 행 클릭 시 지도 포커스
- **T-116** 기간 리포트 화면 — 기간+프로필 선택 → 핫스팟 사용 현황/이동 요약/Top앱/할당량 달성률 요약 화면 + 마크다운 미리보기·복사
- **T-117** 메뉴 구성 통일 + 프로필 미니 통계 — 통계 진입 일원화, 프로필 행에 기간 사용량/할당량 %

## 4. 영향 파일

- `Views/UsageReportView.swift` (인사이트 카드·그래프·리포트 탭)
- `Views/HeatmapMapView.swift` (클러스터·출처 라벨), `Views/HeatmapGridView.swift`
- `Views/PopoverView.swift` (메뉴 통일·프로필 미니 통계·진입)
- `Services/ProfileManager.swift` (전기간 비교·이동 이력 병합·리포트 집계 조회)
- 신규: `Views/InsightCardView.swift`, `Views/MovementTimelineView.swift` (필요 시)

## 5. 테스트 계획

- 단위 테스트: 전기간 비교 집계, 이동 이력 병합(세션+IPLog 시간순), 리포트 요약 집계 (ProfileManager)
- 그래프/지도/타임라인은 수동 검증 + a11y-dump 텍스트 스냅샷

## 6. 롤백 계획

- 스키마 변경 없음 (기존 테이블만 조회) → 커밋 단위 `git revert`로 부분 복구
- T-112~117 각각 독립 커밋, 문제 시 해당 커밋만 revert

## 7. 성능 예산

- 리포트 탭에서만 세션/IP 로드 (탭 전환 시 lazy). 인사이트 카드는 기존 집계 API 재사용.
- 지도 클러스터는 세션 수 1,000 이하 가정, 해시 그룹핑 O(N).
