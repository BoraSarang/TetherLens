# TetherLens v0.36.0

## 새로 추가된 기능
- **업데이트 확인**: 설정 → 업데이트 탭, 또는 팝오버 "..." 메뉴에서 새 버전을 확인합니다. 실행·팝오버 열 때 주기(매 실행/매일/매주)에 맞춰 조용히 확인하고, 새 버전이 있으면 릴리스 노트와 함께 알려줍니다.
- **팝오버 빠른 복사**: 외부 IP 칩 1클릭 복사, 우클릭으로 외부/내부 IP·게이트웨이·SSID·BSSID 복사.
- **인사이트 재설계**: 리포트 차트 탭에 한도 소진 예측·주범 앱·급증·야간 소모·업로드 편중·IP 변경 잦음 6종 표시.

## 개선
- 팝오버 사용 기록 차트를 하나로 합치고(다운 Area + 업 Line), 사용 기록·연결성 기록을 상단에 고정 — 스크롤은 인터페이스부터.
- 리포트 미리보기 네이티브 렌더링(렌더링/원문 토글).

## 설치 방법
1. `TetherLens-v0.36.0.zip`을 다운로드해 압축을 풉니다.
2. `TetherLens.app`을 응용프로그램 폴더에 덮어씁니다.
3. 첫 실행은 Finder에서 우클릭 → '열기'로 허용합니다 (ad-hoc 서명).
