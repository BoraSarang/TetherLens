# TetherLens v0.37.0

## 주요 변경
- **iStat 스타일 시스템 대시보드** — 프로세스 점유율 바 + CPU/GPU/RAM 스파크라인·카드 (플로팅/팝오버/앱 트래픽 3면)
- **메뉴 rename "시스템 대시보드"** — 메뉴·⌘K 팔레트·창 제목 통일, 순서 동일 그리드
- **플로팅 네트워크 카드** — 팝오버 동일 차트 + 큰 숫자 + 프로세스 Top3, 항상 표시
- **안정성·성능 리팩터링** — 크래시 후보 제거, 스냅샷 단일 발행, UI body 고비용 연산 제거

## 설치 방법
1. `TetherLens-v0.37.0.zip`을 다운로드해 압축을 풉니다.
2. `TetherLens.app`을 응용프로그램 폴더에 덮어씁니다.
3. 첫 실행은 Finder에서 우클릭 → "열기"로 허용합니다 (ad-hoc 서명).
