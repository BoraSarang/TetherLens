# TetherLens v0.38.0

## 주요 변경
- **알림 해소 연동** — 핑 끊김/스로틀링 경고 복구 시 시스템 알림센터 알림 제거 + 앱 알림 목록 경고 "해소됨" 마킹 (opacity 0.55 + 체크 아이콘 + 해소 시각). 경고 후속조치(💡팁) 잔류 버그 수정
- **해소 상태 UI** — `AppNotification.resolvedAt` + `isActive`, `NotificationManager` 해소 API (`resolveWarnings`/`resolve(type:)`)
- **복구 플래핑 가드** — 복구 알림이 생략돼도 복구 전환 시점에 해소 (PingMonitor `activeSystemNotificationIds` 추적, ConnectionGuardian 재연결 시 `connectionLost` 해소)

## 수정
- **업데이트 확인 실패** — GitHub API rate limit(익명 60/h)으로 "네트워크 연결을 확인해 보세요" 오류 → API 없이 릴리스 리다이렉트 + raw 노트 조회로 교체. rate limit 시 안내 문구 추가

## 설치 방법
1. `TetherLens-v0.38.0.zip`을 다운로드해 압축을 풉니다.
2. `TetherLens.app`을 응용프로그램 폴더에 덮어씁니다.
3. 첫 실행은 Finder에서 우클릭 → "열기"로 허용합니다 (ad-hoc 서명).
