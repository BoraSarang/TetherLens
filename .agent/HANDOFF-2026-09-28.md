## 4. ⚠️ 다음 세션이 반드시 알아야 할 함정

이것들이 이번에 **실측으로 발견·수정**된 것들이다. 같은 실수를 반복하지 말 것.

1. **`Grid`/`GridRow` 은 자식의 `maxHeight: .infinity` 를 확장하지 않는다.**
   행 높이 동기화가 안 돼 카드 배경이 어긋난다. → `HStack(alignment: .top)` 사용. (PLAN/RelayConsole 이식이 `Grid` 였으나 실측에서 뒤집힘)

2. **`MetricCard` 의 `fillsRow` 프레임은 배경보다 *앞*에 있어야 한다.**
   뒤에 붙이면 뷰만 늘어나고 배경은 자연 높이 그대로. 추가로 `content` 뒤에 `Spacer(minLength: 0)` 가 있어야
   남는 공간이 content 에 배분되지 않아 **카드 제목이 가운데로 안 밀린다**. (`DESIGN.md` §14.3.1 에 근거 기록)

3. **편집 도구는 백슬래시를 포함한 패턴에서 실패한다.**
   `\(self.foo)` 같은 문자열을 oldString 로 넣으면 "찾을 수 없음"이 된다(따옴표 `''` 는 정상 동작).
   → 백슬래시가 포함된 수정은 `python3` heredoc 으로 하고, 결과는 반드시 sed 로 확인.

4. **테스트를 먼저 쓰면 코드 버그를 잡는다.** 이번에 3건:
   - 카드 집합 assertion 이 `wideCards` 를 누락
   - `todayUsedGB` 를 KB 로 가정
   - "프로필 0개 → 인사이트 0개" 가정 — 실제로 `topOffender` 는 **전역** 집계라 나올 수 있음

5. **앱 자동화에서 blind 키 전송 금지.** `key code 116` 이 TetherLens 대신 **Finder** 로 전달돼 파일 창이 열렸다.
   창 포커스 확인 없이 `keystroke` 를 쏘지 말 것. 대안: 카드 토글 키로 특정 카드만 렌더.

6. **nettop 실제 형식은 `time process.pid bytes_in bytes_out`** 이고 `-d` 델타 모드의 **첫 블록은 전부 0**(기준점)이다.
   `samples` 는 재조회 주기(상한 30)와 같게 잡아야 총합이 정확하다(기본 10초면 창 열림 후 ~10초 소요).

7. **시간대 집계는 `getHourlyUsageToday` 만 쓸 것.** `getHourlyUsage(days: 1)` 은 `now - 1day` 기준이라
   어제 야간이 섞이고, 분모 `getTodayUsage`(오늘 자정 이후)와 기간이 어긋나 **비율이 100% 를 넘는다**(실측 186%).

8. **UI 자동화로 캡처할 때 창이 화면 밖으로 밀린다.** AX 로 `position` 을 먼저 조회하고,
   逻辑 해상도(1512×982)를 넘으면 화면 안으로 옮긴 뒤 캡처. `screencapture -R` 은 좌상단 기준이라
   위치가 틀리면 다른 앱이 찍힌다.
