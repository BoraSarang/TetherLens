## 진행 중 / 최신

### v0.39.0 — 대시보드 창 + 팝오버 상세보기 통합 (P0+P1) ✅ 2026-09-27

- **목적**: 메뉴바 팝오버 `상세 보기` 토글로 열던 정보를 **대시보드 창 1개로 통합**. 정보 부족이 아니라 컨테이너 문제였음
- **RelayConsole 콘솔 대시보드 이식** — `DashboardLayout`(순서 단일 진실원처) · `Grid`+`GridRow` 행높이 동기화 · 행 전체 OFF 시 행 붕괴 · 값 없는 지표는 0으로 그리지 않기
- **구성**: 상태바 → 배너 → KPI 5종 → **카드 8칸(4행×2열)** → 푸터.
  1행 [① 실시간 속도 ② 연결 품질] · 2행 [③ 할당량·예측 ④ 오늘 사용 패턴] · 3행 [⑤ CPU ⑥ GPU] · 4행 [⑦ RAM ⑧ 프로세스 리스트]
  + 전폭 ⑨ 눈여겨볼 점(인사이트 6종, 목록형이라 `wideCards` 로 분리) = **총 9칸**
- **팝오더 정리**: `상세 보기` 토글·`summaryMode` 파이프라인 제거(요약 고정), 스크롤 180→92pt, 죽은 코드 369행 제거(1,543→1,145줄)
- **성능 설계**: `DashboardView` 는 `@Published` 를 하나도 관찰하지 않고, 1초 값은 `DashboardClock` 서브뷰로 격리.
  감사에서 확인된 "팝오버 1Hz tick이 body 전체 재렌더" 결함 재발 방지
- **행 높이 동기화**: `Grid`/`GridRow` 은 자식의 `maxHeight: .infinity` 를 확장하지 않아 **실측 실패** →
  `HStack(alignment: .top)` 로 교체. `MetricCard.fillsRow` 프레임은 **배경보다 앞에서** 확장해야 하고,
  content 뒤 `Spacer` 가 남는 공간을 받아 제목을 상단에 고정한다
- **진입점 4곳**: ⌘5 · 우클릭 최상단 · 팝오버 주 버튼 · 커맨드 팔레트 최상단. **리포트(⌘1)는 유지**
- **검증**: `swift build` OK(신규 경고 0) + `scripts/test.sh` **183개/22스위트 통과** (기존 142개/21스위트)
- **GUI 검증**: 8칸 렌더 확인 완료 (스크린샷 `docs/images/dashboard/dashboard-8cells.png`). 검증 중 결함 3건 발견·수정
- **⑨ 눈여겨볼 점**: `InsightProvider`·`InsightPresenter` 로 조립/표시 로직을 분리해 리포트와 공유, `DashboardStore` 가 60초 주기로 상시 계산
- **기존 버그 수정**: 심야 소모 비율 100% 초과(186% 관측) — 시간대 집계의 분자/분모 기간 불일치(`now-1day` vs 오늘 자정). `getHourlyUsageToday` 추가 + 100% 클램프
- **남은 P3**: 카드 On/Off 설정 UI · ② 카드 하단 여백 정리
- 상세: `docs/plans/PLAN_v0.39.0_dashboard_macos.md` · bd TetherLens-d1a/d2b

### 2026-09-27 — 전체 코드·문서 감사 후 정합성 일괄 처리

- **목적**: 기능 추가가 아니라 "구현이 안 된 것"과 "구현된 것의 경계 처리 부실", 그리고 그 상태가 문서에 거짓으로 기재된 문제 해소
- **P0 2건**: 절약모드 `/etc/hosts` 영구 오염(프록시 차단은 UI 해제와 무관하게 잔존) · 프록시 진단 100% 무효(`scutil --proxy` 파싱 오류로 항상 "정상" 반환)
- **P1 5건**: 앱별 트래픽 10배 과소 계상 · 프로세스명 공백 손실 · 핀 고정 후 팝오버 재오픈 불가 · 진단 창 닫기 무동작 · DB 폴백 마이그레이션 누락 · 메뉴바 단축키 8개 동작 불가
- **부수 발견·수정**: `AppShortcuts` 신규(NSEvent 기반 단축키 디스패처) · `parseProxyOutput`/`parse` 순수 함수화 + 회귀 테스트 11개
- **문서 정합 20건**: FR-24(메뉴바 필드 토글)·Sparkle을 5개 문서에서 "✅"로 기재했으나 **코드에 없었음** → 미구현/대체됨으로 확정. FR-20·FR-21·PRD §7 스택도 정정
- **검증**: `swift build` OK + `scripts/test.sh` **142개/21스위트 통과** (기존 131개/19스위트)
- **판정**: **기능 추가는 불필요.** 결측은 FR-24 하나뿐이고 이는 v0.31의 3열 자동 전환으로 이미 대체됨. FR-21(앱별 대역폭 제한)만 `NEFilterDataProvider`(유료 계정) 종속으로 기술적 보류
- 남은 P2 11건은 `docs/TODO.md` T-249~254 — 상세: `docs/CHANGELOG.md` [Unreleased]
