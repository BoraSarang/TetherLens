## Phase 0 — PoC Verification Tests

### TC-001: CoreWLAN SSID on macOS Tahoe 26.5.2

- **Target**: M1 Max MacBook Pro, macOS 26.5.2
- **Steps**:
  1. Set up Xcode project with CoreLocation entitlement
  2. Add NSLocationWhenInUseUsageDescription to Info.plist
  3. Run app, grant Location permission
  4. Read CWWiFiClient.shared().interface()?.ssid()
- **Expected**: Non-nil SSID string
