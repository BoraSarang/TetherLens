### v0.26.0 — 네트워크 진단 센터 + SSID 자동화 + 메뉴바 확장 ✅
- **연결 진단 센터**: VPN/proxy 감지(`scutil --proxy`) · DNS 누수(시스템 vs 설정 대조) · 커스텀 ping · traceroute(12홉) · bufferbloat(idle/부하 RTT) · Markdown 리포트 — 메뉴바 우클릭 "네트워크 진단"
- **SSID 자동화 트리거**: `AutomationRule`(연결/해제, 앱 실행/종료·절약 모드) + 프로필 전환 훅 + 60s 쿨다운, 설정 뷰 관리
- **메뉴바 표시 필드 확장**: BSSID/링크 속도/DNS 토글 3종, **사용 내역 Markdown export** (CSV/JSON 추가)
- 상세: `docs/plans/PLAN_v0.26.0_macos.md`

### v0.26.0 전 — 부록 A 코드베이스 검증 정정 ✅
- 경쟁 분석(COMPETITOR_ANALYSIS 부록 A)을 실제 소스 기준으로 정정: 모든 네트워크(4종) 측정·IP 복사·메뉴바 옵션은 이미 지원, per-app 네트워크 차단은 Apple 유료(NEFilter)로 보류

### v0.23.1 — 메뉴바 할당량 기준 "오늘" 통일 + 에이전트 규칙 정리 ✅
